# Prompt : Rédiger un post de promotion pour "As-tu-lu.fr"

Tu dois rédiger 3 versions différentes d'un post pour promouvoir la plateforme As-tu-lu.fr sur les réseaux sociaux d'auteurs francophones.

## Informations sur la plateforme
- Nom : As-tu-lu.fr
- URL : https://as-tu-lu.fr
- Description : Plateforme francophone qui permet aux auteurs de mettre leurs ebooks gratuits à disposition en échange de l'inscription à leur newsletter.
- Cible : Auteurs francophones (romance, fantasy, SF, thriller, policier, développement personnel, etc.)
- Public visé : Lecteurs passionnés + auteurs qui veulent développer leur liste email

## Objectif
Attirer des auteurs sur la plateforme pour y publier leurs livres gratuits.

## 3 versions à produire
1. Version courte (max 100 caractères) pour X/Twitter
2. Version moyenne (50-80 mots) pour LinkedIn/Threads
3. Version longue + CTA (100-150 mots) pour blog/Instagram caption/Facebook

## Ton à utiliser
- Français, naturel, bienveillant
- Orienté "avantage pour l'auteur" (développer sa liste email, gagner des lecteurs)
- Pas commercial agressif
- Inclure hashtags pertinents

## Hashtags à proposer (au moins 5-8)
Propose des hashtags pertinents : #auteurs #écrivains #auteursfrancophones #ebook #ebookgratuit #newsletter #listeemail #livre #lecteurs #écriture #romance #fantasy #SF #thriller

## CTA obligatoire
Chaque version doit inclure l'URL https://as-tu-lu.fr

## Structure attendue
Pour chaque version : le texte + les hashtags + suggestion de visuel (1 phrase)

Ne pas inventer de fausses données. Reste factuel et utile pour la communauté d'auteurs.
